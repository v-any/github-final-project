# github-final-project

A lightweight command-line utility written in Bash to compute simple interest based on user inputs.

## Description
This project provides a simple script to calculate the total simple interest accrued over a specified time period in years for a given principal amount and annual interest rate.

## Usage
Run the Bash script interactively in your terminal:

```bash
bash simple-interest.sh
Input Parameters
p: Principal amount

t: Time period in years

r: Annual rate of interest

Output
simple interest: Calculated as (p * t * r) / 100
```
